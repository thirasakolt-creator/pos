เชื่อมจากอินเทอร์เน็ต (ไม่ต้องอยู่ Wi‑Fi เดียวกัน)
  1. บน PC: รัน start-server.bat + start-tunnel.bat
  2. คัดลอก URL จาก tunnel เช่น https://xxx.trycloudflare.com
  3. ใส่ URL นั้นในช่อง Bridge ด้านบน (+ Token ถ้ามี)
  4. อัปเว็บ GitHub แล้วเปิดจากมือถือที่ไหนก็ได้

ลิงก์: ?bridge=https://xxx.trycloudflare.com&token=รหัส
