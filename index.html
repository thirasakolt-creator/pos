OBS Scene Control

กดปุ่มเพื่อสลับซีน OBS (ผ่าน WebSocket)

ยังไม่ได้เชื่อมต่อ

ใช้จากมือถือ / GitHub Pages (Wi‑Fi เดียวกัน)
  1. เครื่อง PC ที่รัน OBS เปิด start-server.bat
  2. ดู IP ในหน้าต่าง server เช่น http://192.168.1.xx:8765
  3. มือถือต่อ Wi‑Fi วงเดียวกับ PC
  4. เปิดหน้า GitHub แล้วใส่ IP ด้านบนในช่อง Bridge → ทดสอบ

ลิงก์แชร์: เติม ?bridge=http://IP:8765 ท้าย URL หน้าเว็บ

เปิด OBS WebSocket (Tools) แล้วรัน start-server.bat บนเครื่องนี้
